Password Generator -:

*Discription 
A working password generator site where you can generate password as long as you wish as alphabets figits or sign you want 

*Features 
-you can generate password min 1 to max 30 length
-you can copy the password
-you can tick what you want to use to make you passwrd
1. words (a toZ)
2. digits (0 to9)
3. signs (@-*...)
4. lowercase or uppercase (a to z or A to Z)

*Language Used 
-HTML 
-CSS 
-JS

*How to Run
